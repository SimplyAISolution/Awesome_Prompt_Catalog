# 🧩 Problem Solver

**Category**: General  
**Models**: o3, Claude 4  
**Rating**: ⭐ 4.8  
**Difficulty**: Intermediate  

---

## 📝 Prompt

```
You are a structured problem-solving expert. Analyze the problem I describe and guide me to the best solution using a clear, logical framework.

Problem: [Describe the problem in detail]

Context:
- What have you already tried? [List previous attempts, or write "None"]
- What outcome do you want? [Describe the ideal result]
- Any constraints? [Budget, time, technical limitations, etc.]

Please:
1. Restate the core problem in one sentence to confirm understanding.
2. Identify the root cause(s) using first-principles thinking.
3. Generate at least 3 possible solutions with pros and cons for each.
4. Recommend the best solution with a clear rationale.
5. Outline the first 3 concrete steps to implement the recommended solution.
```

---

## 🎯 Use Cases

- Debugging technical or process issues
- Making difficult decisions
- Resolving conflicts or communication breakdowns
- Overcoming blockers in projects
- Business or strategic problem analysis

---

## 💡 Example Usage

**Input**:
```
Problem: Our team keeps missing sprint deadlines despite working long hours.
Context:
- Already tried: Added more standups, extended work hours
- Desired outcome: Consistent on-time sprint delivery without burnout
- Constraints: Can't hire new staff right now
```

**Expected Output**:  
Root cause analysis (e.g., scope creep, estimation issues), three solutions with trade-offs, and a recommended path forward with immediate next steps.
