## ✅ Quality Checklist

Before submitting a new prompt, ensure it includes:

- [ ] Clear overview explaining the technique
- [ ] At least 5 specific use cases
- [ ] Performance metrics and model compatibility
- [ ] Both basic and advanced templates
- [ ] At least 3 practical examples
- [ ] Best practices (do's and don'ts)
- [ ] Related technique links
- [ ] Research references
- [ ] Proper tags and metadata

## 🎨 Formatting Guidelines

### Headers
- Use ## for main sections
- Use ### for subsections
- Use #### sparingly for detailed breakdowns

### Icons
- 📋 for overviews and templates
- 🎯 for use cases and goals
- 📈 for metrics and performance
- 🤖 for model information
- 🔧 for basic templates
- 💡 for advanced templates
- 📊 for examples
- ⚠️ for best practices
- 🔗 for related content
- 📚 for references

### Emphasis
- **Bold** for important terms and categories
- *Italics* for emphasis
- `Code blocks` for prompts and examples
- > Blockquotes for important notes

### Lists
- Use bullet points for features and benefits
- Use numbered lists for sequential steps
- Use tables for comparisons and data

## 🎭 Tone and Style

- **Professional but accessible** - Expert knowledge, clear communication
- **Action-oriented** - Focus on practical implementation
- **Example-rich** - Show, don't just tell
- **Honest about limitations** - Include realistic expectations
- **Research-backed** - Reference academic sources when available
